# 🦠 Análise COVID-19 no Brasil

Análise exploratória de dados da pandemia de COVID-19 no Brasil, 
usando um dataset de 3,8 milhões de registros do brasil.io.

## 📊 Sobre o projeto

Este projeto faz parte do meu portfólio em Ciência de Dados. 
O objetivo é explorar a evolução da pandemia no Brasil entre 
fevereiro de 2020 e março de 2022, respondendo perguntas sobre 
contaminação, mortalidade e diferenças regionais.

## 🔍 Perguntas respondidas

- Qual foi a evolução dos casos confirmados ao longo do tempo?
- Quais estados tiveram maior taxa de contaminação por 100k habitantes?
- Como as regiões do Brasil foram afetadas de forma diferente?
- Quais estados registraram maior taxa de letalidade?

## 🛠️ Ferramentas utilizadas

- Python 3
- pandas
- matplotlib
- Jupyter Notebook

## 📁 Dados

Dataset público disponível em [brasil.io/dataset/covid19](https://brasil.io/dataset/covid19)

- 3.853.648 registros originais
- 18 colunas
- Cobertura: fevereiro de 2020 a março de 2022
